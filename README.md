## Overview
School Management System built with Odoo 18 to manage student data, tuition payment, online exams, and WhatsApp integration.

## Features
- Student data management
- SPP / tuition payment module
- Online exam module
- WhatsApp integration
- Custom Odoo modules

## Tech Stack
- Odoo 18
- Python
- PostgreSQL
- XML
- HTML/CSS/JavaScript

## Modules
- al_spp_school
- al_ujian_online_school
- al_whatsapp_school
- sistem_sekolah_odoo18
