Cara Kerja

Setup dalam 5 menit

1

Install Addon

Pastikan Sistem Sekolah sudah terinstall, lalu install addon WhatsApp ini

2

Pilih Provider

Buka menu Sekolah > WhatsApp > Konfigurasi, pilih provider WhatsApp API

3

Masukkan API Token

Dapatkan API Token dari provider yang dipilih dan masukkan ke konfigurasi

4

Atur Template Pesan

Sesuaikan template pesan dengan variabel yang tersedia

5

Aktifkan

Aktifkan konfigurasi dan sistem siap digunakan

Variabel Template

Gunakan variabel ini dalam template pesan Anda

{nama_siswa}

Nama lengkap siswa

{kelas}

Nama kelas siswa

{nis}

Nomor Induk Siswa

{tanggal}

Tanggal absensi

{mapel}

Mata pelajaran
